**Datei:** `260714_rueckschau_biotop.html`
**Autor:** Friedemann Decker · Juli 2026

## Was ist das?

Der Rückschau-Bericht zum Projekt „Biotop: Competitive Game of Life"
(WIAI25-Projektmesse, 26.06.2026) als fertig gestaltete Webseite —
blogartig, mit Diagrammen, Studien-Grafiken, einem eingebetteten Video
und einer live im Browser laufenden Simulation (Rot gegen Blau).

## Nutzung

Die Datei ist **vollständig eigenständig**: Text, Stylesheet, JavaScript,
alle Grafiken (SVG) und das Video (Base64) stecken in dieser einen Datei.
Es gibt keine externen Abhängigkeiten — sie lädt nichts nach und braucht
keine weiteren Dateien, keinen Webserver und keine Internetverbindung.

- **Ansehen:** Datei per Doppelklick in einem aktuellen Browser öffnen
  (Chrome, Firefox, Edge, Safari).
- **Veröffentlichen:** Datei unverändert auf den Webserver legen und
  verlinken — fertig. Alternativ kann der Inhalt (alles innerhalb von
  `<body>` plus der `<style>`- und `<script>`-Block) in eine bestehende
  CMS-Seite übernommen werden.
