Markdown-Datei `NNNN-slug.md` nach der NYT-Logik *Frage → Evidenz → Einordnung*.

Erstellt mit dem Skill `data-story` (`.claude/skills/data-story/`). Jede Story
ruht ausschließlich auf der Codebase (`eurovision-data/`); extern recherchierte
Fakten sind im Frontmatter unter `recherche` gesondert ausgewiesen.
